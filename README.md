# কোচিং ম্যানেজার

কোচিং সেন্টারের জন্য ৩ অংশের একটি অ্যাপ। **Next.js 15 (App Router) + Supabase + Tailwind CSS**।

| অংশ | ঠিকানা | কে দেখে |
|---|---|---|
| **অ্যাডমিন (শিক্ষক)** | `/dashboard`, `/students`, `/batches`, `/attendance`, `/fees`, `/exams`, `/site`, `/settings` | শুধু লগইন করা শিক্ষক |
| **পাবলিক ওয়েবসাইট** | `/` (হোম), `/batch/[id]` (ব্যাচ পেজ), `/apply` (ভর্তি ফর্ম) | সবাই |
| **অভিভাবক/শিক্ষার্থী পোর্টাল** | `/p/[গোপন-টোকেন]` | যার কাছে গোপন লিংক আছে (শুধু দেখা) |

## ১. Supabase সেটআপ (ফ্রি)

1. https://supabase.com এ প্রজেক্ট খুলুন।
2. **SQL Editor** এ নিচের দুটো ফাইল **ক্রমানুসারে** পেস্ট করে Run করুন:
   1. `supabase/schema.sql`
   2. `supabase/002_portal_site.sql` (পোর্টাল, ওয়েবসাইট, ভর্তি ফর্ম, ছবির স্টোরেজ)
3. **Authentication → Users → Add user** থেকে শিক্ষকের ইমেইল/পাসওয়ার্ড দিয়ে ইউজার বানান (Auto Confirm টিক দিন)।
4. নতুন সাইন-আপ বন্ধ করুন (**Allow new users to sign up** অফ), যাতে বাইরের কেউ অ্যাকাউন্ট খুলতে না পারে।
5. **Project Settings → API** থেকে `Project URL` ও `anon public` key কপি করুন।

## ২. নিজের কম্পিউটারে চালানো

```bash
npm install
cp .env.example .env.local     # URL ও key বসান
npm run dev
```

http://localhost:3000 এ পাবলিক সাইট, http://localhost:3000/login এ অ্যাডমিন লগইন।

## ৩. প্রথমবার যা সাজাবেন

1. **সেটিংস:** সেন্টারের নাম, লোগো, ঠিকানা, ফোন।
2. **ওয়েবসাইট:** শিক্ষকের ছবি ও পরিচিতি, হিরো শিরোনাম, কোচিং সম্পর্কে, ভর্তির তথ্য, যোগাযোগ, গ্যালারির ছবি।
3. **ব্যাচ:** ব্যাচ বানান। প্রতিটি ব্যাচে "ওয়েবসাইটে দেখানোর সেটিং" থেকে বিবরণ ও ফি দেখানো/লুকানো ঠিক করুন।
4. **শিক্ষার্থী:** যোগ করুন, ব্যাচে ভর্তি করুন।

## ৪. কীভাবে কাজ করে

- **অভিভাবক পোর্টাল:** "শিক্ষার্থী" পেজে প্রতিটি শিক্ষার্থীর পাশে গোপন লিংক আছে। "WhatsApp-এ পাঠান" চাপলে অভিভাবকের নম্বরে লিংক সহ মেসেজ তৈরি হবে। সেখানে হাজিরা, এ মাসের বকেয়া, পেমেন্ট ইতিহাস, রসিদ ও পরীক্ষার নম্বর দেখা যায়। লিংক ফাঁস হলে "লিংক বদলান" দিন, পুরনোটা সাথে সাথে অচল।
- **অনলাইন ভর্তি:** `/apply` থেকে আসা আবেদন "শিক্ষার্থী" পেজের উপরে "অপেক্ষমাণ" হিসেবে আসে (নেভিগেশনে সংখ্যা দেখায়)। "অনুমোদন" দিলে শিক্ষার্থী সক্রিয় হয় এবং আবেদনের ব্যাচে ভর্তি হয়ে যায়।
- **কৃতী শিক্ষার্থী:** "পরীক্ষা" → পরীক্ষা খুলে নম্বর দিন → নিচে সেরা ৩ জন দেখাবে। ছবি দিয়ে ও **অভিভাবকের সম্মতি টিক দিয়ে** "হোম পেজে দিন" চাপুন।
- **ব্যাচ ড্যাশবোর্ড বাটন:** হোম পেজের প্রতিটি ব্যাচ কার্ডে "ব্যাচ ড্যাশবোর্ড" বাটন আছে। সেটি ঐ ব্যাচের পাবলিক পেজে নিয়ে যায় (সময়সূচি, শিক্ষার্থী সংখ্যা, বিবরণ, ঐ ব্যাচের কৃতী শিক্ষার্থী, ভর্তির বাটন)।

## ৫. Vercel-এ ডিপ্লয়

1. GitHub-এ পুশ করে Vercel-এ ইমপোর্ট করুন।
2. Environment Variables: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`।
3. Deploy।

> **মনে রাখবেন:** Vercel Hobby (ফ্রি) প্ল্যান শুধু ব্যক্তিগত/অবাণিজ্যিক কাজের জন্য। কোচিং সেন্টারের আসল ব্যবহারে Vercel Pro নিন, অথবা Cloudflare Pages/Netlify-তে ডিপ্লয় করুন (তাদের বর্তমান শর্ত দেখে নিন)।

## ৬. নিরাপত্তা ও গোপনীয়তা

- সব অ্যাডমিন টেবিলে Row Level Security চালু। পাবলিক পেজ ও পোর্টাল টেবিল সরাসরি পড়ে না; শুধু তিনটি নির্দিষ্ট ডাটাবেস ফাংশন (`get_public_site`, `get_portal`, `submit_application`) দিয়ে সীমিত তথ্য বের হয়।
- পোর্টালের টোকেন এলোমেলো UUID; অনুমান করা প্রায় অসম্ভব। পোর্টাল পেজ সার্চ ইঞ্জিনে ইনডেক্স হয় না।
- ভর্তি ফর্মে বট ঠেকাতে লুকানো ঘর (honeypot) আছে এবং ডাটাবেসে ঘণ্টায় ৩০টির বেশি আবেদন নেওয়া হয় না।
- **শিক্ষার্থীর নাম/ছবি পাবলিক সাইটে দেওয়ার আগে অভিভাবকের সম্মতি নিন।** ফর্মে সম্মতি টিক বাধ্যতামূলক রাখা হয়েছে।
- ছবির সীমা: প্রতিটি ১.৫ MB, গ্যালারিতে একবারে ৩টি (Vercel-এ একটি রিকোয়েস্টের সীমা প্রায় ৪.৫ MB)। ছবি মুছলে ডাটাবেস থেকে সরে যায়, তবে Storage-এ ফাইল থেকে যায়; দরকার হলে Supabase Dashboard → Storage → `site-images` থেকে মুছুন।

## ৭. ফোল্ডার কাঠামো

```
supabase/schema.sql            প্রধান টেবিল + RLS
supabase/002_portal_site.sql   পোর্টাল/ওয়েবসাইট/ভর্তি/স্টোরেজ + পাবলিক ফাংশন
src/middleware.ts              কোন পেজ পাবলিক, কোনটা লগইন লাগে
src/app/(public)/              হোম, ব্যাচ পেজ, ভর্তি ফর্ম
src/app/p/[token]/             অভিভাবক পোর্টাল + রসিদ
src/app/(app)/                 অ্যাডমিন পেজসমূহ
src/app/login                  লগইন
```

## ৮. পরিচিত সীমাবদ্ধতা

- একজন শিক্ষকের জন্য বানানো। একাধিক শিক্ষক/ব্রাঞ্চ যোগ করলে পাবলিক সাইট কোন শিক্ষকের তথ্য দেখাবে তা ঠিক করতে হবে।
- PWA আইকন এখন SVG; কিছু ফোনে ইনস্টলের জন্য 192×192 ও 512×512 PNG আইকন `public/` এ রেখে `manifest.webmanifest` এ যোগ করুন।
- এই কোড আমার এনভায়রনমেন্টে `npm install`/বিল্ড করে পরীক্ষা করা হয়নি (নেটওয়ার্ক বন্ধ ছিল)। প্রথম রানে কোনো এরর এলে জানান।
